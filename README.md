# abir-weeding

Royal Wedding Invitation Website for Md. Abdul Ramim (Abir) & Mosammet Somaiya Akter (Nishi).

Built with React, Vite, and Vanilla CSS. Features bilingual (Bangla/English) support, scratch-to-reveal save the date, animated rose petals, countdown timer, background audio, and live field-by-field admin control panel.
